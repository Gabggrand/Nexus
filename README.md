## Nexus Neo — Website Oficial do Console (Projeto Front-End)

Este projeto é um site oficial fictício para o console Nexus Neo, incluindo páginas de jogos, acessórios, trailer e suporte.
Foi desenvolvido com foco em design moderno, responsividade e experiência do usuário, utilizando React + Vite.

## 🚀 Tecnologias Utilizadas

React

Vite

React Router DOM

CSS inline / estilos personalizados

Imagens e design gerados com IA (Gemini)

## 📌 Funcionalidades

Destaques do console

Trailer e apresentações visuais

Navegação rápida para jogos e acessórios
